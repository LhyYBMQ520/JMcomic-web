<h1 align="center">JMComic Web</h1>

基于 [jmcomic](https://github.com/hect0x7/JMComic-Crawler-Python) 库的 Web 工具，提供漫画搜索、信息预览、后台下载与本地 ZIP 打包，并支持管理员统一管理用户、任务配额和缓存清理。

后端使用 FastAPI 与 SQLite，前端使用原生 HTML、CSS 和 JavaScript，无需单独安装 Node.js 或构建前端资源。

## 功能特性

- **漫画搜索**：支持全站、作品、作者、标签和角色搜索，以及排序、分类筛选与分页。
- **信息预览**：通过 JM 车号查询标题、作者、页数和章节数，支持批量输入。
- **后台下载**：任务在服务端执行，通过 Server-Sent Events（SSE）向网页推送进度。
- **本地打包**：使用 `jmcomic.Feature.export_zip` 在图片下载完成后生成 ZIP，不调用远程 ZIP 接口。
- **用户管理**：管理员可创建账户、生成或修改访问令牌、设置备注、启停账户和删除账户。
- **任务隔离**：任务查询与文件下载按所属账户校验权限，并按用户、任务分别保存文件。
- **并发控制**：支持全站与单用户运行数、队列容量限制，以及单任务车号数量限制。
- **持久化与恢复**：使用 SQLite WAL 模式保存用户和任务，启动时恢复等待中及被服务重启中断的任务。
- **定时清理**：按任务过期时间清理已结束任务的图片、ZIP 和数据库记录。
- **配置热重载**：支持在运行期间更新管理员令牌。

## 快速开始

### 1. 获取项目

```bash
git clone https://github.com/LhyYBMQ520/JMcomic-web.git
cd JMcomic-web
```

也可以下载源码 ZIP，解压后进入包含 `run.py` 的项目根目录。

### 2. 安装依赖

推荐为本项目创建单独的 `venv` 虚拟环境，或使用 conda 创建独立的 Python 环境（Python 3.11 或更高版本）。以下安装和启动命令均在所选环境中执行。

Windows cmd：

```bat
python -m pip install -r requirements.txt
```

Linux / macOS：

```bash
python3 -m pip install -r requirements.txt
```

### 3. 启动服务

Windows cmd：

```bat
python run.py
```

Linux / macOS：

```bash
python3 run.py
```

默认访问地址：[http://127.0.0.1:8000](http://127.0.0.1:8000)。使用 `Ctrl+C` 停止服务。

首次启动会自动生成项目根目录下的 `config.toml`，并初始化 `data/app.db`。管理员令牌来自配置模板，普通用户令牌的加密密钥则在首次生成配置时随机创建。

### 4. 设置管理员令牌并登录

打开 `config.toml`，将 `[auth].admin_token` 替换为自己的随机令牌。可以使用所选环境中的 Python 生成令牌：

```python
import secrets
print(secrets.token_urlsafe(32))
```

只修改管理员令牌，保留本节其他配置，尤其是首次生成的 `token_encryption_key`：

```toml
admin_token = "替换为你生成的随机令牌"
```

默认启用热重载，保存后通常在 2 秒内生效；若关闭热重载，则需重启服务。

在首页输入该令牌登录，进入下载工作台。管理员可直接访问 [http://127.0.0.1:8000/admin](http://127.0.0.1:8000/admin) 管理普通用户。

## 使用指南

### 搜索与下载

1. 使用管理员或管理员分配的普通用户令牌登录。
2. 在「搜索漫画」中输入关键词，选择搜索范围、排序方式和分类，点击「搜索」。
3. 点击结果中的「加入下载」，将车号加入下载输入框；也可以直接输入已知车号。
4. 多个车号用空格或换行分隔，仅支持纯数字车号，默认单次最多 20 个，可在配置文件中进行调整。
5. 点击「预览信息」，确认作品信息后点击「开始下载」。
6. 等待后台任务完成，点击「下载 ZIP 文件」将 ZIP 包保存到自己的设备。

后端会对车号去重。修改输入内容后，应重新预览再开始下载。

图片和 ZIP 首先保存到运行服务的设备，点击下载链接才会将 ZIP 传输到浏览器所在设备。默认完成后保留 30 分钟，请及时保存文件。

### 账户与权限

| 功能 | 普通用户 | 管理员 |
| --- | --- | --- |
| 搜索、预览和提交下载任务 | 支持 | 支持 |
| 查询与下载自己账户的任务 | 支持 | 支持 |
| 管理普通用户账户与令牌 | 不支持 | 支持 |
| 查询或下载其他账户的任务 | 不支持 | 当前任务接口不提供跨账户访问 |

暂未对普通用户开放自助注册入口，当前仅可由管理员在 `/admin` 创建。令牌长度要求为 12–256 个字符，备注最多 200 个字符。管理页面支持生成随机令牌、查看当前令牌、修改备注、启用或禁用账户，以及删除账户。

禁止多人共用同一账户。共用令牌会共享任务配额、任务访问权和文件下载权限；会造成各种各样的问题，所以每位使用者应有独立账户。

修改令牌或禁用账户后，旧令牌无法通过后续认证；这些操作不会取消已经提交的下载任务。删除账户前，该账户必须没有运行中或等待中的任务。删除成功后，其任务记录及对应下载、归档目录会一并移除。

### 登录会话

网页登录后设置 `jm_session` Cookie，有效期为 24 小时，登录生效期间访问网页会自动跳转 `/app` （网页主界面），使用 `HttpOnly` 和 `SameSite=Strict`。令牌失效、账户禁用或 Cookie 到期后需要重新登录。页面中的「退出登录」会清除当前浏览器的会话 Cookie。

## 配置说明

配置文件为项目根目录下的 `config.toml`。不存在时自动生成；修改前建议备份。

相对路径以项目根目录为基准，也支持绝对路径和环境变量展开。Windows 路径建议使用正斜杠，例如 `D:/JMComic/downloads`，避免 TOML 双引号字符串中的反斜杠转义问题。

### 服务、下载与数据库

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `server.host` | `"127.0.0.1"` | 默认仅本机访问；局域网访问可设置为 `"0.0.0.0"` |
| `server.port` | `8000` | HTTP 服务端口 |
| `download.max_ids_per_task` | `20` | 单次预览或下载允许的去重后车号数量上限，最小有效值为 1 |
| `download.base_dir` | `"data/downloads"` | 图片下载目录 |
| `download.archive_dir` | `"data/archives"` | ZIP 归档目录 |
| `database.path` | `"data/app.db"` | SQLite 数据库文件路径 |

### 认证与热重载

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `auth.admin_token` | 配置模板中的默认令牌 | 管理员访问令牌，首次使用时应替换为自己的随机令牌 |
| `auth.token_encryption_key` | 首次生成配置时随机创建 | 32 字节密钥的 URL-safe Base64 编码，用于加解密普通用户令牌 |
| `auth.secure_cookie` | `false` | HTTPS 部署设为 `true`；本地 HTTP 使用 `false` |
| `config_reload.enabled` | `true` | 是否启用管理员令牌热重载 |
| `config_reload.interval_seconds` | `2` | 配置文件修改检查间隔，单位为秒，最小有效值为 1 |

认证使用令牌的 SHA-256 摘要。普通用户令牌另外以 AES-GCM 加密保存，管理员接口可解密查看；数据库本身并非整体加密。

`token_encryption_key` 必须与数据库一起妥善保存。更换或丢失它会导致已保存的普通用户令牌无法解密查看，但已有摘要仍可用于验证原令牌。不要为了更换管理员令牌而删除整个配置文件。

当前热重载会更新管理员令牌和 `secure_cookie`，不会更新加密密钥。`secure_cookie` 的变化影响之后创建的登录 Cookie。服务、目录、配额、清理策略及热重载开关、检查间隔等配置修改后需重启生效。

### 任务配额

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `limits.global_running_tasks` | `2` | 全站同时运行的任务数，最小有效值为 1 |
| `limits.global_queued_tasks` | `50` | 全站等待容量，可设为 0 |
| `limits.per_user_running_tasks` | `1` | 单账户同时运行的任务数，最小有效值为 1 |
| `limits.per_user_queued_tasks` | `3` | 单账户等待容量，可设为 0 |

提交任务时，后端按「运行数上限 + 等待容量」检查全站及单账户的未结束任务总数。默认全站最多接受 52 个未结束任务，单账户最多接受 4 个。达到上限会返回 HTTP 429。

一个任务可以包含多个车号，任务内按输入顺序下载；每部作品的图片还会由 `jmcomic` 并发下载。因此任务运行数不等于图片下载线程数，调整配额时应结合网络、磁盘和内存情况。

### 缓存清理

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `cleanup.enabled` | `true` | 是否启动定时清理器 |
| `cleanup.interval_minutes` | `2` | 检查间隔，单位为分钟，最小有效值为 1 |
| `cleanup.retention_minutes` | `30` | 任务每次保存状态时，从当前时间计算的保留时长，单位为分钟 |

启用清理时，服务启动会检查一次，随后按配置间隔检查。只清理数据库中已结束且过期的任务，包括已完成、失败以及标记为中断的任务；运行中和等待中的任务不在清理范围内。

`retention_minutes = 0` 表示已结束任务可在启动检查或下一次定时检查时立即被清理，并不表示删除下载目录中的所有内容。清理器也不会按文件修改时间扫描任意文件。

修改保留时长不会重新计算已经结束任务的过期时间；新设置在重启后影响随后保存的任务状态。如需长期保存服务端文件，可设置 `cleanup.enabled = false` 并自行管理存储空间。

## 任务与文件管理

### 任务状态与恢复

当前下载流程的主要状态为：

```text
pending（等待） → downloading（下载与本地打包） → completed（完成）
                                           ↘ failed（失败）
```

服务重启后，数据库中的 `pending` 任务会重新加入队列；`downloading` 或 `packing` 状态的任务会先改为 `pending` 再重新排队执行。这是任务恢复，不保证从上一次页数精确续传。失败任务不会自动重新排队，需要重新提交。

关闭浏览器不会取消服务端下载。当前网页没有任务历史列表，也不会在刷新后自动找回任务；需要继续查询时，可使用创建任务接口返回的 `task_id`，通过 API 获取状态和文件。

### 文件布局与打包方式

默认保存结构：

```text
data/
├── app.db
├── app.db-wal                         # 可能存在的 SQLite WAL 文件
├── app.db-shm                         # 可能存在的 SQLite 共享内存文件
├── downloads/<user_id>/<task_id>/     # 图片及 jmcomic 生成的目录
└── archives/<user_id>/<task_id>/      # 最终 ZIP
```

- 单车号任务：输出 `<车号>.zip`。
- 多车号任务：输出 `<车号1>_<车号2>_….zip`，其中包含每部作品各自的 ZIP，即 ZIP 内嵌 ZIP。
- 完成或失败任务到期后，清理器移除其图片目录、归档目录及任务记录。原下载链接随后失效。

### 备份与迁移

建议在停止服务后备份 `config.toml`、数据库文件及所需下载和归档目录；数据库目录中仍存在的 `-wal`、`-shm` 文件也应一并保留。恢复时保持配置中的加密密钥与数据库匹配。

任务记录保存的是归档文件绝对路径，迁移到不同目录或设备后，旧任务的下载路径可能失效；仅修改下载目录配置不会迁移旧文件或更新旧任务路径。

## 部署说明

### 本机与局域网

默认监听 `127.0.0.1:8000`，只允许本机访问。需要从同一局域网的其他设备访问时，在配置中设置：

```toml
[server]
host = "0.0.0.0"
port = 8000
```

重启后，其他设备使用 `http://<服务端局域网IP>:8000` 访问，并按需要放行系统防火墙中的对应端口。`0.0.0.0` 是监听地址，不是浏览器访问地址。

### HTTPS 与反向代理

对外提供服务时，使用反向代理终止 HTTPS，将请求转发至本机运行的应用，并将 `[auth].secure_cookie` 设置为 `true`。首次使用前替换模板中的管理员令牌。

代理应转发完整路径，允许 ZIP 文件下载，并支持 `/api/tasks/{task_id}/events` 的长连接。对 SSE 响应关闭代理缓冲，并设置合适的读取超时，否则网页进度可能延迟显示。

前端请求使用 `/api/...` 等根路径，部署时应让应用位于域名根路径；当前没有子路径部署配置。HTTPS 模式下应从 HTTPS 地址登录，避免浏览器拒绝发送 Secure Cookie。

### 运行约束

- 使用 `run.py` 启动单个应用进程。当前任务队列、线程池和事件队列都在进程内，不支持多个 Uvicorn worker 或多个实例共享同一数据库调度任务。
- 可使用系统服务或进程管理工具维持运行，但对同一数据目录只运行一个实例。
- 默认启用 FastAPI 的 `/docs`、`/redoc` 和 `/openapi.json`，这些文档入口本身不要求登录；受保护的业务接口仍需认证。如需限制文档入口，可在反向代理层配置访问规则。
- `config.toml` 包含管理员令牌和加密密钥，数据库包含用户与任务信息，应限制文件读取权限。发布源码或提交代码时不要包含实际配置、数据库、下载内容或个人令牌文件。

## 接口说明

运行后可在 [Swagger UI](http://127.0.0.1:8000/docs) 或 [ReDoc](http://127.0.0.1:8000/redoc) 查看参数与数据结构。

### 认证方式

业务 API 接受 `X-Access-Token` 请求头，或者登录后获得的 `jm_session` Cookie。两者同时存在时优先使用请求头。

`POST /api/session` 使用请求头中的令牌创建浏览器会话，`DELETE /api/session` 清除会话 Cookie。清除 Cookie 不会撤销令牌本身。

### 接口列表

| 方法 | 路径 | 权限 | 用途 |
| --- | --- | --- | --- |
| `GET` | `/`、`/login` | 公开 | 登录页；有效 Cookie 会重定向到 `/app` |
| `GET` | `/app` | 已登录 | 下载与搜索工作台 |
| `GET` | `/admin` | 管理员 | 用户管理页面 |
| `POST` | `/api/session` | 有效令牌 | 创建登录会话 |
| `DELETE` | `/api/session` | 无需认证 | 清除登录 Cookie |
| `GET` | `/api/settings` | 已登录 | 获取网页所需的单任务车号上限 |
| `POST` | `/api/preview` | 已登录 | 批量预览漫画信息 |
| `POST` | `/api/search` | 已登录 | 搜索漫画 |
| `POST` | `/api/tasks` | 已登录 | 创建任务，成功返回 HTTP 202 |
| `GET` | `/api/tasks/{task_id}` | 任务所属账户 | 查询任务状态 |
| `GET` | `/api/tasks/{task_id}/events` | 任务所属账户 | 订阅 SSE 进度 |
| `GET` | `/api/tasks/{task_id}/file` | 任务所属账户 | 下载已完成任务的 ZIP |
| `GET` | `/api/admin/users` | 管理员 | 列出普通用户及其令牌 |
| `POST` | `/api/admin/users` | 管理员 | 创建普通用户，成功返回 HTTP 201 |
| `PATCH` | `/api/admin/users/{target_user_id}` | 管理员 | 更新备注、启用状态和可选的新令牌 |
| `DELETE` | `/api/admin/users/{target_user_id}` | 管理员 | 删除用户及其任务数据 |

### 请求示例

预览或创建任务的 JSON 请求体：

```json
{
  "ids": ["350234", "114514"]
}
```

创建任务成功时返回：

```json
{
  "task_id": "实际返回的任务ID",
  "status": "pending"
}
```

任务可能在响应返回前已经开始运行，应以实际返回值及后续状态为准。

搜索请求体：

```json
{
  "query": "搜索关键词",
  "page": 1,
  "search_type": "site",
  "order_by": "mr",
  "time": "a",
  "category": "0"
}
```

`search_type` 支持 `site`、`work`、`author`、`tag`、`actor`。网页提供的排序值为 `mr`（最新更新）、`mv`（最多浏览）、`mp`（页数最多）、`tf`（最多喜欢）；分类值为 `0`、`doujin`、`single`、`short`、`hanman`、`meiman`、`3D`。搜索词最多 100 个字符，页码范围为 1–9999。

管理员更新用户时，`note` 和 `enabled` 省略会使用接口默认值，建议明确传入希望保留的值；`token` 为 `null` 或省略时保留原令牌。

### 常见响应状态

| 状态码 | 含义 |
| --- | --- |
| `400` | 车号或搜索参数无效，或上游预览、搜索请求失败 |
| `401` | 未登录、令牌无效或账户已禁用 |
| `403` | 当前账户没有管理员权限 |
| `404` | 任务或用户不存在、不属于当前账户，或文件尚未准备好、已被移除 |
| `409` | 用户令牌冲突，或账户仍有未结束任务而无法删除 |
| `422` | 请求体字段未通过类型、长度等校验 |
| `429` | 全站或当前账户的任务配额已满 |

## 常见问题

### 启动时提示找不到 `tomllib`

检查正在使用的 Python 版本。项目需要 Python 3.11 或更高版本；确认虚拟环境也是由满足要求的解释器创建。

### 已安装依赖，启动仍提示模块不存在

确认安装和启动使用同一个 Python，并且当前终端使用的是所选的 `venv` 或 conda 环境，避免系统中多个解释器混用。

### 访问 `/app` 或 `/admin` 返回 401 / 403

先访问 `/` 登录。401 表示认证未通过，403 表示当前账户不是管理员。如果启用了 `secure_cookie`，确认浏览器使用 HTTPS 访问。

### 忘记管理员令牌

在服务端修改 `config.toml` 中的 `[auth].admin_token`，使用新令牌登录。热重载关闭时需要重启。不要修改普通用户令牌加密密钥。

### 管理页面无法显示某个用户的原令牌

仅有摘要的旧数据无法还原原令牌；加密密钥丢失或更换也会导致解密失败。管理员可以为该账户设置新令牌并保存。

### 搜索、预览或下载失败

确认输入的是纯数字车号或有效搜索词，并检查服务端到上游的网络连接。查看页面中的错误详情和运行终端输出。搜索封面由浏览器直接请求，封面加载失败还需检查浏览器所在设备的网络。失败任务需要重新提交。

### 提示任务队列已满

等待已有任务结束后重试，或调整 `[limits]` 后重启。一个包含多个车号的任务占用一个任务名额，但可能持续更长时间。

### 进度不更新，或者刷新后找不到任务

先检查网络与反向代理是否允许 SSE 长连接、是否缓冲响应。网页刷新后不会自动恢复任务视图，后台任务仍会执行；已保存 `task_id` 时可通过任务 API 查询。当前没有任务历史列表。

### 完成后无法下载，或 ZIP 内还有 ZIP

任务文件可能已经过期清理，或迁移后原路径失效。默认完成后保留 30 分钟，清理按 2 分钟间隔检查。多车号任务的最终文件内包含各作品独立 ZIP，这是当前打包方式。

### 能否使用多个 worker、取消任务或自动重试？

当前只支持单个应用进程，没有取消任务和失败后自动重试接口。服务重启恢复未结束任务不等于自动重试失败任务，也不保证精确断点续传。
